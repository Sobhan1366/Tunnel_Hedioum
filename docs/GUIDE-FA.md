# راهنمای خیلی ساده‌ی نصب (قدم‌به‌قدم، مخصوص مبتدی‌ها)

این راهنما فرض می‌کنه **هیچ چیزی از سرور و لینوکس نمی‌دونی**. فقط کافیه دستورها رو **عیناً کپی و پیست** کنی.
هر مرحله یه «چک‌لیست» داره که بفهمی درست پیش رفتی یا نه. اگه جایی گیر کردی برو به بخش «۹. مشکل داری؟».

---

## ۰. این چیه و چی لازم دارم؟

یه تونل می‌سازیم تا کاربرها از طریق دو سرور به اینترنت آزاد وصل بشن:

```
گوشی/کامپیوتر کاربر  →  سرور ایران (هاب)  →  سرور خارج  →  اینترنت
```

**چیزهایی که لازم داری:**

| چیز | توضیح |
|---|---|
| **سرور ایران** | یه VPS داخل ایران (به اسم «هاب»). اوبونتو ۲۲ یا ۲۴ مناسبه. |
| **سرور خارج** | یه VPS خارج از ایران (به اسم «خروجی»). اوبونتو، حداقل ۱ گیگ رم. |
| **کامپیوتر** | ویندوز، مک یا لینوکس برای وصل‌شدن به سرورها. |
| **رمز یا کلید SSH** | که هاستینگ بهت داده (معمولاً رمز کاربر `root`). |

> نکته‌ی مهم: **همه‌ی سرورهای خارج یکسان کار نمی‌کنن.** بعضی IPها از ایران بدون هیچ دلیل واضحی «داده رد نمی‌کنن». برای همین قبل از نصب، یه تست سریع می‌گیریم (مرحله‌ی ۳).

---

## ۱. چند کلمه که باید بدونی

| کلمه | یعنی چی |
|---|---|
| **سرور / VPS** | یه کامپیوتر اجاره‌ای که همیشه روشنه |
| **IP** | آدرس سرور، مثل `94.1.2.3` |
| **SSH** | راهی برای وصل‌شدن به سرور و تایپ دستور |
| **ترمینال** | پنجره‌ای که توش دستور تایپ می‌کنی |
| **root** | کاربر مدیر سرور |
| **هاب** | سرور ایران |
| **سرور خارج / خروجی** | سروری که ترافیک ازش به اینترنت می‌ره |
| **توکن جفت‌سازی** | یه رشته‌ی طولانی که دو سرور رو به هم وصل می‌کنه (محرمانه!) |
| **لینک `vless://`** | چیزی که به کاربر می‌دی و توی برنامه‌ی کلاینت وارد می‌کنه |
| **پنل** | یه صفحه‌ی وب برای ساخت و مدیریت کاربرها |

---

## ۲. وصل‌شدن به سرور (فقط بار اول)

### ویندوز
۱. کلید `Windows` رو بزن، بنویس `PowerShell` و بازش کن.
۲. این رو بزن (به‌جای `IP_سرور` آدرس واقعی رو بذار):
```
ssh root@IP_سرور
```
۳. اولین بار می‌پرسه `Are you sure...?` بنویس `yes` و Enter بزن.
۴. رمز رو وارد کن. **موقع تایپ رمز چیزی نشون داده نمی‌شه — این عادیه.** Enter بزن.

✅ اگه خط‌ات این‌شکلی شد (`root@...:~#`) وصل شدی.

برای خروج: `exit` بزن.

### مک / لینوکس
همون دستور `ssh root@IP_سرور` توی Terminal.

> ⚠️ **چند بار پشت‌سرهم نزن!** اگه رمز رو غلط بزنی یا بارها وصل بشی، بعضی سرویس‌ها (مثل Vultr) آدرس تو رو چند دقیقه می‌بندن. یه بار، آروم، درست.

---

## ۳. قبل از نصب: سرور خارج مناسبه؟ (تست ۲ دقیقه‌ای)

### ۳-۱. فایل‌های پروژه رو روی هاب بذار
هاب ایران معمولاً **به گیتهاب دسترسی نداره**، پس از کامپیوتر خودت می‌فرستیم:

۱. توی مرورگر برو به: `https://github.com/Sobhan1366/Tunnel_Hedioum`
۲. دکمه‌ی سبز **Code** ← **Download ZIP**. فایل رو از حالت فشرده دربیار (Extract).
۳. توی PowerShell این رو بزن (مسیر پوشه رو با مسیر خودت عوض کن):
```
scp -r C:\Users\نام_تو\Downloads\Tunnel_Hedioum-main root@IP_هاب:/root/Tunnel_Hedioum
```

### ۳-۲. روی هاب یه «کلید» برای وصل‌شدن به سرور خارج بساز
وصل شو به **هاب** (مرحله‌ی ۲) و این رو بزن:
```
ssh-keygen -t ed25519 -N "" -C "check-foreign" -f /root/.ssh/check_key
```
بعد کلید عمومی رو ببین و **کپی کن**:
```
cat /root/.ssh/check_key.pub
```
(یه خط طولانیه که با `ssh-ed25519` شروع می‌شه.)

### ۳-۳. اون کلید رو به سرور خارج بده
وصل شو به **سرور خارج** (مرحله‌ی ۲ با IP سرور خارج) و این رو بزن. به‌جای `متن_کلید` همون خطی که کپی کردی رو بذار:
```
mkdir -p ~/.ssh && chmod 700 ~/.ssh && echo 'متن_کلید' >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys
```
بعد `exit` بزن.

> اگه رمز SSH سرور خارج رو داری و هاب می‌تونه بهش وصل بشه، به‌جاش می‌تونی روی **هاب** بزنی:
> `ssh-copy-id -i /root/.ssh/check_key.pub root@IP_سرور_خارج`

### ۳-۴. تست رو اجرا کن (روی هاب)
```
cd /root/Tunnel_Hedioum
bash tools/check-foreign.sh IP_سرور_خارج --key /root/.ssh/check_key
```
حدود ۱ تا ۲ دقیقه طول می‌کشه. آخرش یه کلمه می‌نویسه:

| نتیجه | یعنی چی | کار بعدی |
|---|---|---|
| **GOOD** ✅ | سرور مناسبه | برو مرحله‌ی ۴ |
| **MARGINAL** ⚠️ | نسبتاً قابل قبول ولی مطمئن نیست | یه بار دیگه تست کن، یا سرور دیگه امتحان کن |
| **BAD** ❌ | از ایران داده درست رد نمی‌کنه | **سرور رو عوض کن** (با یه دیتاسنتر/کشور دیگه) |

اگه نوشت «port 587 is already used»: `--port 465` به آخر دستور اضافه کن.

---

## ۴. نصب روی سرور خارج

وصل شو به **سرور خارج** و این‌ها رو بزن:
```
curl -fsSL -o install-kharej.sh https://raw.githubusercontent.com/Sobhan1366/Tunnel_Hedioum/main/kharej/install-kharej.sh
```
```
bash install-kharej.sh
```
اسکریپت چند سوال می‌پرسه. **برای همه‌شون فقط Enter بزن** (یعنی مقدار پیش‌فرض خوبه).

✅ آخرش یه کادر می‌نویسه که یه دستور `scp` توشه. **اون دستور رو کپی کن**، برای مرحله‌ی بعد لازمه.

---

## ۵. نصب روی هاب ایران

وصل شو به **هاب** و بسته‌ی ساخته‌شده رو از سرور خارج بیار (دستوری که مرحله‌ی قبل دادش):
```
scp -r root@IP_سرور_خارج:/root/iran-bundle /root/
```
(رمز سرور خارج رو می‌خواد.)

بعد نصب:
```
cd /root/Tunnel_Hedioum
bash iran/install-iran.sh --bundle /root/iran-bundle
```
باز هم چند سوال: **همه‌ش Enter**.

✅ آخرش یه لینک `vless://...` چاپ می‌کنه. این لینک اولین اتصاله.

### وارد کردن لینک توی برنامه
- **کامپیوتر (ویندوز):** برنامه‌ی **v2rayN** ← لینک رو کپی کن ← توی برنامه `Ctrl+V` بزن (یا منوی Servers ← Import from clipboard).
- **اندروید:** **v2rayNG** یا **NekoBox** ← علامت `+` ← Import config from clipboard.
- **آیفون:** **Streisand** یا **V2Box** ← `+` ← Import from clipboard.

بعد وصل شو و توی مرورگر برو به `ifconfig.me`. باید IP **سرور خارج** رو ببینی. اگه دیدی: تبریک، کار می‌کنه! 🎉

### پاک‌کردن فایل محرمانه (حتماً)
روی **هر دو سرور**:
```
rm -rf /root/iran-bundle
```

## ۶. پنل کاربران (حجم، تاریخ انقضا، تمدید ماهانه)

برای این‌که بتونی برای هر کاربر **حجم و تاریخ انقضا** بذاری، پنل نصب می‌کنیم.

### ۶-۱. فایل نصب پنل رو به هاب برسون (چون هاب به گیتهاب نمی‌رسه)
۱. توی مرورگر کامپیوتر این رو دانلود کن:
`https://github.com/MHSanaei/3x-ui/releases/latest/download/x-ui-linux-amd64.tar.gz`
۲. توی PowerShell بفرست به هاب:
```
scp C:\Users\نام_تو\Downloads\x-ui-linux-amd64.tar.gz root@IP_هاب:/root/
```

### ۶-۲. شماره‌ی «پورت سوکس» هدیوم رو پیدا کن (روی هاب)
```
grep local_socks_port /etc/hedioum/hedioum.json
```
عددی که دیدی (مثلاً `40001`) رو یادت نگه دار.

### ۶-۳. نصب پنل (روی هاب)
به‌جای `40001` عدد خودت رو بذار:
```
cd /root/Tunnel_Hedioum/panel
bash install-panel.sh --tarball /root/x-ui-linux-amd64.tar.gz --socks-port 40001
```
✅ آخرش یه کادر می‌نویسه با: **آدرس پنل، نام کاربری، رمز**. جاش امن یادداشتش کن (توی `/root/panel-credentials.txt` هم ذخیره شده).

### ۶-۴. ساخت کاربر (روی هاب)

**کاربر با ۳۰ گیگ در ماه که خودش هر ماه تمدید می‌شه:**
```
bash add-user.sh ali --monthly 30
```

**کاربر نامحدود (حجم و زمان):**
```
bash add-user.sh me
```

**۵۰ گیگ، ۶۰ روزه:**
```
bash add-user.sh sara --gb 50 --days 60
```

**حداکثر ۲ دستگاه هم‌زمان:** `--devices 2` رو به آخر هر دستور اضافه کن.

هر دستور یه لینک `vless://` می‌ده. **همون رو به کاربر بده** (مثل مرحله‌ی ۵ توی برنامه وارد می‌کنه).

### ۶-۵. دیدن و مدیریت کاربرها
```
bash list-users.sh
```
(نشون می‌ده هر کاربر چقدر مصرف کرده و کی تموم می‌شه.)

لینک یه کاربر رو دوباره ببین:
```
bash show-link.sh ali
```

حذف کاربر:
```
bash remove-user.sh ali
```

> **توجه:** کاربرهای لینک مرحله‌ی ۵ (بدون پنل) **حجم و محدودیت ندارن**. فقط کاربرهایی که با `add-user.sh` می‌سازی محدودیت دارن.

---

## ۷. سرعت بیشتر (اختیاری)

هدیوم هر اتصال رو روی ۸ مگابیت محدود می‌کنه. برای سرعت بیشتر (روی هاب):
```
hedioum-tunnel edit-node --alias KHAREJ --bw 100 --jitter 0 --min 12 --max 30
```
```
systemctl restart hedioum
```
(به‌جای `KHAREJ` اسم نودت رو بذار.) سرعت یه دانلود تکی تا حدود ۵ برابر می‌شه، ولی ترافیک کمتر «عادی» به نظر می‌رسه. سرعت **کل** بین همه‌ی کاربرها مشترکه و معمولاً حدود ۵۰ مگابیت سقف داره؛ نود اضافه به همون سرور اون رو بیشتر نمی‌کنه.

## ۸. ری‌استارت تصادفی (اختیاری، برای کمتر شناسایی‌شدن)

موقع نصب هر دو سرور، وقتی پرسید «Install the randomized-restart timer?» جواب `y` بده. تونل در ساعت‌های نامنظم ری‌استارت می‌شه. **این کار جلوی همه‌ی انواع شناسایی رو نمی‌گیره**؛ فقط الگوی «اتصال خیلی طولانی و ثابت» رو می‌شکنه.

## ۹. مشکل داری؟

| مشکل | علت و راه‌حل |
|---|---|
| `Permission denied` موقع SSH | رمز یا کلید اشتباهه. دوباره **یک بار** امتحان کن. |
| `Connection timed out / reset` | ممکنه IP شما موقتاً بسته شده باشه. ۵ تا ۱۰ دقیقه صبر کن، بعد یه بار دیگه. |
| `Could not resolve` یا گیتهاب باز نمی‌شه روی هاب | عادیه. فایل‌ها رو از کامپیوتر با `scp` بفرست (مرحله‌ی ۳-۱ و ۶-۱). |
| تست سرور **BAD** شد | سرور خارج رو عوض کن (دیتاسنتر/کشور دیگه). |
| وصل می‌شم ولی اینترنت نمی‌آد | روی هاب `systemctl status hedioum xray-iran` بزن؛ هر دو باید `active` باشن. بعد `systemctl restart hedioum` بزن. |
| کاربر پنل وصل نمی‌شه | برنامه‌اش باید **Reality** و **XTLS-Vision** رو پشتیبانی کنه (v2rayN/NekoBox/Streisand جدید). برنامه رو به‌روز کن. |
| پنل باز نمی‌شه | آدرس رو دقیق (با مسیر مخفی آخرش) وارد کن. پورت پنل ممکنه توسط فایروال هاستینگ بسته باشه. |
| بعد از ری‌بوت سرور چیزی کار نمی‌کنه | ۲ دقیقه صبر کن و `systemctl restart hedioum xray-iran x-ui` بزن. |

## ۱۰. نکات ایمنی

- **لینک‌ها، توکن، رمز پنل و کلیدها رو برای هیچ‌کس جز صاحبشون نفرست و جایی پست نکن.**
- بعد از نصب `rm -rf /root/iran-bundle` رو بزن.
- رمز پنل رو بعد از ورود عوض کن.
- پنل رو روی پورت عمومی بدون رمز قوی نذار.
- از سرورهای مهم و فعال بک‌آپ بگیر قبل از تغییر دستی.

> این پروژه ابزار حفظ حریم خصوصی و دسترسی به اینترنت آزاده. هیچ تضمینی نیست که شناسایی یا بلاک نشه؛ شرایط شبکه همیشه در حال تغییره.
